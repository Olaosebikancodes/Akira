# Bundled fonts

The Latin subsets of these fonts ship with Akira so text looks the same on every machine. They come from [Fontsource](https://fontsource.org) (version 5.3.0), which repackages the upstream font projects. Each licence is in `licenses/`.

| Font | Weights | Licence |
|---|---|---|
| Inter | 400, 700 | SIL Open Font License 1.1 |
| Montserrat | 400, 700 | SIL Open Font License 1.1 |
| Poppins | 400, 700 | SIL Open Font License 1.1 |
| Bebas Neue | 400 | SIL Open Font License 1.1 |
| Anton | 400 | SIL Open Font License 1.1 |
| Playfair Display | 400, 700 | SIL Open Font License 1.1 |
| Pacifico | 400 | SIL Open Font License 1.1 |
| Permanent Marker | 400 | Apache License 2.0 |
